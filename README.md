A [make.fun](https://make.fun) entry for the **Famous Last Words at 1 Percent** competition: the funniest one-line farewell a phone could say as its battery hits 1 percent.

## The line

The phone's screen speaks its own farewell — it lit up every late-night scroll, every text, every face, and its grand finale is the display itself dying mid-word, the sentence cut off exactly where the pixels give out.

## How it works

`main.ts` writes the single line to `/output/entry.txt`. Run it with:

```sh
node main.ts
```
